# RentRecord update package — 17 November 2026

This package contains revised files for the RentRecord GitHub repository. It is a file update bundle, not a complete runnable project.

## Apply
Replace the matching files in the repository with the files in this archive, preserving the folder structure. Review the changes before committing.

## Included changes
- Bills screen separates overdue, coming-up and marked-paid records, shows monthly totals and offers a status filter.
- A roadmap panel describes future Gmail import, authorised supplier/e-invoice connections and a later payment-provider assessment.
- Local benefits includes an illustrative area map and linked sample offer cards.
- Every business, area pin and offer in the map is fictional; there are no real partner listings or exact addresses.
- Project documentation explains what is implemented, what needs browser verification, and what remains future work.

## Verification status
The source was prepared but no browser acceptance test was run. Bills, map interactions and the updated documentation still need a browser review before presentation.
